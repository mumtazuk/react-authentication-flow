# React Authentication Flow

This project provides a simple authentication flow using React, Material-UI, and React Hooks. The application includes the following features:

- **Login**: Users can log in with their email and password.
- **Signup**: New users can create an account with validation for email, password, and confirm password.
- **Forgot Password**: Users can request a password reset link by providing their registered email.

## Features

- **Material-UI**: Styled components using Material-UI to ensure a clean and responsive UI.
- **Form Validation**: Email, password, and confirmation fields are validated for correctness and required inputs.
- **Snackbars**: Show success or error messages using Material-UI Snackbar component.
- **Password Visibility Toggle**: Password fields have visibility toggles for easy input.

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Material-UI**: A popular React UI framework for styled components.
- **React Hooks**: Used for state management and component lifecycle management.

## Setup Instructions

1. Clone this repository to your local machine:

    ```bash
    git clone https://github.com/your-username/react-authentication-flow.git
    ```

2. Navigate into the project directory:

    ```bash
    cd react-authentication-flow
    ```

3. Install the dependencies using Yarn or npm:

    ```bash
    yarn install
    ```

 
4. Run the development server:

    ```bash
    yarn start
    ```

5. Open your browser and navigate to `http://localhost:3000`.
